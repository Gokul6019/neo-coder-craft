# Gokul Raj V — Futuristic Developer Portfolio

> Aspiring Software Engineer & AI/ML Developer

A high-end, futuristic developer portfolio for **Gokul Raj V** — a 1st-year B.Tech CSE (AI & ML) student at NIAT × SVYASA University, Bengaluru. Built as a coding command center with a dark neon aesthetic, glassmorphism cards, terminal-style hero, animated grid/particles, and a mouse-following glow.

## 🌐 Live Website

**🔗 https://neo-coder-craft.lovable.app**

Open the link above to view the live portfolio.

## ✨ Features

- **Terminal-style hero** with a typing effect introduction
- **About**, **Skills** (Currently Learning + Growing Strengths), **Education/timeline**, **Projects**, **Achievements**, **GitHub**, and **Contact** sections
- **Glassmorphism cards**, glowing borders, animated grid background, scanlines, and particles
- **Mouse-following glow** and smooth scroll animations
- Fully **responsive** (mobile / tablet / desktop)
- **Accessible** contrast, keyboard navigation, semantic HTML, and reduced-motion support
- Centralized, fully **editable** data file (`src/lib/portfolio-data.ts`)

